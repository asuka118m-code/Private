# レシピ帳

ネットのレシピ・スクショ・SNSの投稿からレシピを取り込んで保存する、スマホ向けWebアプリ（PWA）です。

## できること
- **取り込み**
  - URL：レシピサイトのページを読み込み、材料・手順を取り出す（schema.orgのRecipe情報に対応しているサイトはAIなしでも取り込める）
  - スクショ：画像からAIが材料・手順を読み取る。スクショは「参考画像」として保存
  - テキスト：Instagram・X・YouTube説明欄などの文章を貼り付けて取り込む（AIなし・無料で整形。「レシピ名：」で区切れば複数レシピを一括登録）
  - 共有：Androidでホーム画面に追加すると、SNSの「共有」から直接このアプリへ送れる
- **保存形式**：材料は1行ずつ「材料名 …… 分量」、作り方は番号付きの手順
- **参考元**：URLと画像をレシピごとに保存
- **作った料理の写真**：あとから追加でき、一覧の表紙にもなる（タップで表紙を変更）
- **一覧**：タイトルと画像のカード表示、料理名・材料で検索
- **編集・削除**：材料と手順の追加・並べ替え・削除
- **感想コメント**：★評価つきで何度でも残せる。編集画面に過去の感想が出るので、改善に使える

データは端末内（ブラウザのIndexedDB）に保存されます。「バックアップ」画面から全データを1ファイルに書き出し・復元できます（別端末への移行にも使用可）。

## 起動
```bash
npm install
npm run build
ANTHROPIC_API_KEY=sk-ant-... npm start   # http://localhost:3000
```
- `ANTHROPIC_API_KEY` がなくても動きます。ただしスクショの読み取りはできず、URL・テキストの取り込みはルールベースの推測になります。
- AIはClaude（既定 `claude-opus-5-5`、`CLAUDE_MODEL` で変更可）を使います。
- 開発時：`npm run dev`（Vite + APIサーバー）、テスト：`npm test`

スマホで使うにはHTTPSで公開する必要があります（Render・Railway・Fly.ioなど、Nodeが動くサービスならデプロイ可）。
