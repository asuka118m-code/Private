# insta-caption

このフォルダには、実際に動く道具が1つある。

道具のある場所は、このSKILL.mdが入っているフォルダ（ふつうは `~/.claude/skills/insta-caption/`）。
以下の `<このスキルのフォルダ>` はそこに置き換えて実行する。

```bash
python3 "<このスキルのフォルダ>/caption.py" caption.txt
python3 "<このスキルのフォルダ>/caption.py" caption.txt --keywords "電気代 節約,固定費 見直し"
```

フィードで見える形でキャプションを表示する。最初の部分を枠で囲み、それ以外は「…続きを読む」の向こう側。
書いたものの中で、まずその枠を読むこと。

作業用のファイル（caption.txt）は、ユーザーの作業フォルダか一時フォルダに書く。スキルのフォルダには書かない。

## 日本語のキャプションは「幅」と「行」で切れる

英語版は「125文字」で切れる前提だったが、日本語は文字数では決まらない。
漢字・ひらがな・カタカナ（全角）は、英数字（半角）の2倍の幅をとる。さらに、改行と空行の位置でも切れる。

`caption.py` は次の近似（だいたいの目安）で「見える部分」を計算する。

- 全角＝2、半角＝1 として幅を数え、合計 **60（全角30文字ぶん）** を超えたところで切る（`--truncate`）
- 表示が **2行** を超えたところで切る。改行・空行・折り返しを1行と数える（`--lines`）
- 1行の幅は **40（全角20文字ぶん）** で折り返す（`--line-width`）

実際の切れ目は、機種・文字の大きさ・アカウント名の長さ、そしてInstagramの仕様変更で変わる。
ぴったりを狙わず、**最初の一文を全角25文字くらいまでに収めておく** のが安全。結果を伝えるときも「近似です」と添える。

## まず、このキャプションの役目を決める

ここを飛ばすと、キャプションは失敗する。

**役目A：動画がもう引きつけている。** リールはそれ自体が最初の2秒にフック（話す一言とテロップ）を持っている。
キャプションは2つ目のフックではない。動画と張り合うと、両方負ける。
役目は、お願い・お願いの理由になる補足・検索される言葉。

**役目B：キャプションが本体。** 写真1枚、カルーセルの表紙など。
この場合は1行目がフックで、リールのフックと同じ考え方：具体的に、短く、「続きが気になる」所で切れるように。

どちらを書くのか決めて、ユーザーに言う。フックの強いリールなら、Aで書いて理由を添える。

## 形

```
1行目       見える範囲（全角30文字ぶん・2行が目安）。役目Aならお願いを素直に、役目Bならフック。
            あいさつ・ハッシュタグ・絵文字から始めない。
本文        短い段落を2〜6個。段落の間は空行1つ。2〜4行ごとに空行を入れる。
            検索されたいキーワードはここに入れる。
お願い      1つだけ。キーワードのコメント、保存、シェア、DMのどれか。
ハッシュタグ  最大5個。いちばん下にまとめるか、付けない。
```

上限は2,200文字。ほとんどのキャプションは、そんなに要らない。タップさせてから600文字で中身を渡すほうが、1,800文字よりうまくいく。

## 日本語キャプションの作法

- **改行と空行を使う。** スマホでは、空行の無い長文は「文字の壁」に見えて読まれない。1段落は2〜4行まで。
- **絵文字は句読点がわり。** 飾りとして並べない。行頭の絵文字の箇条書きはAIっぽく見えやすい。100文字あたり4個を超えると `caption.py` が注意を出す。
- **顔文字・記号（♪☆）も同じ。** 1つの段落に1つまで、を目安に。
- **検索されるキーワードを本文に入れる。** Instagramの検索は、キャプションの文章を読む。
  見つけてほしい言葉は、ハッシュタグのかたまりではなく、人が検索窓に打つ形のまま文章に入れる。
  例：「#電気代節約」だけでなく、本文に「電気代の節約」と書く。
- **保存・シェアをうながす一言を入れる。** 例：「あとで見返せるように保存してね」「同じことで悩んでる友達に送ってあげて」。
  ただし、お願いは1つ。保存とシェアとフォローを全部頼まない。

## ハッシュタグについて

元のスキル（英語版）の作者は「Instagramは2025年12月18日に、1投稿あたりのハッシュタグを30個から5個までに減らした」と書いている。
この日本語版はその情報を引き継いでいるが、**元のスキル作成時点の情報** なので、Instagramの最新の案内を優先する。
上限が変わっていたら `--max-tags` で変える。

考え方は変わらない：ハッシュタグは「たくさん付けて見つけてもらう道具」ではなく、「何の投稿かを表すラベル」。
具体的なものを最大5個。メモアプリに20個ためてある定番タグのかたまりは、もう重荷にしかならないので `caption.py` は落とす。

`#おすすめ` `#おすすめにのりたい` `#いいね返し` `#フォローミー` `#instagood` `#fyp` などは、何の投稿かを何も表していない。消す。

## ルール

- **キャプションにリンクを貼らない。** キャプションのURLは押せない。プロフィールのリンクかDMで渡す。
- **お願いは1つ。** 2つ頼むと、どちらもされない。`caption.py` が数える。
- **コメントしてもらうキーワードは、打ちやすい1語に。** 短く、空白なし、絵文字なし。動画の中でも声に出して言う。
  `『電気代』ってコメントしてね` は良い。`『電気代の見直しガイドがほしい』ってコメントしてね` は打ってもらえない。
- **リンクを渡す必要があるなら**、最初のコメント（固定コメント）やDMの文面を別に書いて、そう伝える。
- **代替テキスト（画像の説明文）も20秒で書く。** カルーセルや写真なら書いておく。画面読み上げを使う人と、Instagramの両方が読む。
- **作らない。** 実績・数字・お客さんの声を作らない。わからない数字は `{{あなたの数字}}` のまま残して、そう伝える。

## 進め方

1. 役目AかBかを決めて、ユーザーに言う。
2. 下書きする。
3. `/insta-natural` を通す。キャプションは短いので、AIっぽい言い回しがどこよりも目立つ。
4. 本人の検索キーワードを付けて `caption.py` を実行する。「NG」はすべて直す。「注意」は、直すか残すかを黙って決めず、理由を言う。
5. コピーしやすいようにコードブロックで本文を出し、そのあとに受け取り票を出す：

```
キャプション完成
役目：         A ― リールがフックを持っている
見える範囲：   1行目は全角26文字（近似の見える範囲に収まっている）
お願い：       1つ、保存
ハッシュタグ：  3個
検索キーワード： 「電気代」は1行目、「固定費」は最後の段落
点検：         投稿OK（READY）
```

何も投稿しない。貼り付けて投稿するのは本人。
