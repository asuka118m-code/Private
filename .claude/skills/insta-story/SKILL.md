# insta-story（ストーリーズ係）

ストーリーズは「小さいフィード」ではありません。
フィードやリールは、知らない人に見つけてもらう場所。ストーリーズは、**すでにフォローしてくれている人が「この人から買いたいか」を決める場所** です。そして、タップひとつで会話（DM）が始まる、Instagramで唯一の場所でもあります。

フォロワー以外にはほとんど届かないので、仕事がまったく違います。広げるのではなく、深めるのが仕事です。

## 1日の流れ

1日3〜7枚。7枚を超えると、飛ばされる割合が上がり、最後の数枚はほとんど誰も見ていません。そして多くの人は、まさにその最後の数枚にお願いを置いてしまいます。

```
1枚目      はじまり   今日起きていること。顔か手が映っているもの。
2〜3枚目   なかみ     本題：やっている途中、結果、失敗。日常 → 気づき の順に。
4枚目      問いかけ   スタンプをひとつ。アンケート、質問箱、クイズ、リンクのどれか。
5枚目      しめ       答え、結果、または明日へのつなぎ。
```

お願いは7枚目ではなく4枚目に置きます。1枚進むごとに見ている人は減るので、残っている人がいるうちに見せます。

## 日本でよく効く「日常 → 気づき」の流れ

日本のストーリーズでは、いきなり売り込むより、**日常の出来事から入って、そこで気づいたことを話し、自分の発信テーマにつなげる** 流れが好まれます。

- 日常：「今朝、子どもの水筒を洗いながら…」
- 気づき：「毎日同じことに10分使ってるって、ふと思った」
- テーマへ：「家事の"ついで"を減らすと、1日30分は浮く。私がやめた3つ、明日話すね」

日常の部分は事実だけにします。起きていない出来事を作って書かない。

## スタンプと、それぞれの本当の役割

| スタンプ | 役割 | 使う場面 |
| --- | --- | --- |
| **アンケート** | いちばん気軽な1タップ | 情報より「反応の数」がほしいとき |
| **質問箱（質問スタンプ）** | 見ている人の言葉をそのまま集める | 投稿ネタや、買わない理由（不安・迷い）を本人の言葉で知りたいとき |
| **クイズ** | 間違えてもらって覚えてもらう | ジャンルによくある思い込みがあるとき |
| **絵文字スライダー** | 気分の確認 | 大事な用途はない。息抜き用 |
| **リンク** | プロフィール以外で唯一押せる場所 | 本当に行き先があるとき（公式LINE、ブログ、申込ページなど） |
| **カウントダウン** | 通知を受け取れる締め切り | 発売、ライブ配信、締め切りの告知 |
| **「あなたの番」（Add Yours）** | フォロワー外へのたまの広がり | ジャンルの誰もが答えられるお題のとき |

いちばん過小評価されているのは **質問箱** です。集まった答えはすべて、キャプション・リールのフック・DMの第一声の材料になります。しかも見ている人自身の言葉です。`insta-reel` の hooks.json にある「よくある質問型」（#18）のフックとして渡します。

アンケートの選択肢は、答えやすさが命です。「はい／いいえ」より「わかる！／まだ大丈夫」のように、どちらを選んでも気まずくない言い方にします。

## ルール

- **1枚目には顔か手を。** 色の背景に文字だけの1枚目は飛ばされます。1枚目で残りを見るかどうかが決まります。
- **1枚にひとつのこと。** ストーリーで長文を読む人はいません。
- **文字は画面の中央寄りに。** 1080×1920の画面で、上から250ピクセルより上と、1600ピクセルより下には大事な文字を置かない。上にはアカウント名の列、下には返信欄が重なります。
- **ひとりに話しかける。** 「みなさん」より「あなた」。ストーリーズは、DMではないものの中でいちばんDMに近い場所です。
- **自分のフィード投稿を、ひとことも添えずにシェアしない。** いちばん飛ばされる1枚です。紹介するなら、コメント欄で何が起きているか、なぜ見に行く価値があるのかを書きます。
- **売るのは投稿より、ストーリーズで。** 背景3枚・案内1枚・実績（事実のみ）1枚。同じ内容のフィード投稿より売れやすく、発見タブでの広がりも削りません。
- **実績・お客様の声は事実だけ。** 本人の許可を取ったもの、実際の数字だけを使います。足りなければ `{{あなたの数字}}` と書いて知らせます。

## DMへの導線を、正直に

うまくいく流れはこうです。悩みを言い当てるストーリー → 「それ私だ」と言えるアンケートか質問箱 → 答えてくれた人ひとりひとりに返信。
**相手が先に話しかけてくれたから、会話が始まります。**

キーワードで自動返信するDMは、プロアカウント向けにInstagram自身の機能や、Metaの審査を通った連携ツールで正式に使えます。反応していない人へのDM一斉送信は認められておらず、アカウントが制限される原因になります。ルールは単純です。**相手が先に動き、こちらは返す。**

## 出力

1枚ずつ、画面に映るもの・話すこと・使うスタンプを順に書き、最後に「集まった答えをどう使うか」を書きます。

```
ストーリーズ ・ 火曜 ・ 5枚

1  [手元：水筒を洗っている]   「毎朝これに10分。地味にしんどい」
2  [画面録画：家事の時間メモ]  「1週間はかったら、"ついで家事"だけで70分だった」
3  [顔・話す]                 「全部やめなくていい。3つやめるだけで変わる」
4  [アンケート]               「"ついで家事"多い自覚ある？」 あるある！ ／ わりと少ない
5  [写真に文字]              「明日、私がやめた3つを話すね。気になる人はこのストーリーに返信してね」

このあと：「あるある」に投票してくれた人に、ひとことずつ返信する。それが導線のすべて。
要確認：「70分」は例です。実際にはかった数字に置き換えてください。
```
