# insta-carousel（図解投稿係）

カルーセルは、フィードの中でいちばん長く見てもらえる形式です。スワイプは「操作」なので、ただ流し見されるより強い反応として数えられます。
しかも、2回目のチャンスがあります。1回目に反応しなかった人へ、2枚目以降から表示し直されることがあるので、**2枚目も単体で成り立つ**必要があります。

この形式は「ひとつの考えを手順に分けたもの」に強く、「キャプションを切って並べただけのもの」に弱いです。

## リールではなくカルーセルにするとき

**順番があって、読み返したくなる内容** のときはカルーセル：手順、いくつかの要素に分かれた考え方、ビフォーアフター、スクショしたくなる一覧。
**動き・顔・目の前で起きるオチ** が必要なときはリール。

主張がひとつだけなら、どちらでもありません。`insta-reel` に回し、そう伝えます。

## 構成

6〜10枚。上限は20枚ですが、20枚は誰も読み終えない本です。5枚未満だとスワイプが始まりません。

```
1枚目        表紙      フック。大きな文字で15文字前後まで。サムネイルの大きさでも読めること。
                      その下に「この投稿で手に入るもの」を1行。
2枚目        なぜ大事か  なぜこれがあなたに関係あるのかを1文で。ここは2枚目の表紙でもあるので、前置きにしない。
3〜N枚目     1枚1テーマ  見出し（8〜15文字）＋本文60文字前後まで。説明が長くなるなら2枚に分ける。
N+1枚目      まとめ     全部を1枚の一覧に。スクショされて送られる1枚。
最後          お願い     ひとつだけ。保存、キーワードをコメント、フォローのどれか。
```

## 日本語のスライド文章のルール

- **表紙が結果の8割。** 「保存しておきたい」と思わせる言葉を1枚目に置きます。日本では「保存版」「完全版」「◯選」「やってはいけない◯つ」「知らないと損する」などがよく使われますが、中身が伴わない煽りは逆効果です。中身に合う言葉だけ使います。
- **1枚の文字量は少なく。** 目安は見出し＋本文で80文字以内。スマホの画面では実物の3分の1くらいの大きさで読まれます。文字を詰めたくなったら、それは2枚に分けるサインです。
- **漢字が続きすぎないように。** 漢字が4〜5文字以上続くと読みにくくなります。ひらがなを混ぜる、言い換える。
- **改行は意味の切れ目で。** 単語の途中や助詞の前で改行しない（「保存し／ておく」のような切れ方をしない）。
- **体言止めと短い文を中心に。** ただし全部を体言止めにすると箇条書きの寄せ集めに見えるので、要所は文で言い切ります。
- **数字は具体的に。** 「たくさん節約」より「月3,000円節約」。ユーザーの実際の数字がなければ `{{あなたの数字}}` と書いて知らせ、作らない。
- **ページ番号を入れる**（3/8など）。終わりが見えると、最後まで読まれやすくなります。
- **まとめの1枚は、それだけで意味がわかるように。** 送る・スクショされるのはこの1枚です。送られる（シェアされる）のは、獲得できるいちばん強い反応です。
- **全ページの隅に小さくアカウント名。** スクショは持ち主の名前なしで出回ります。
- **代替テキスト（画像の説明文）を少なくとも表紙に。** 読み上げ機能を使う人のためで、Instagram側も内容の理解に使います。投稿時の「詳細設定」から入れられます。

## 画面の切れ方に気をつける

プロフィールのグリッド（一覧）では、縦長の画像が中央で切り取られて表示されます。その比率はこれまでに何度も変わっています。
**1080×1350（4:5）で作り、表紙の文字は四辺から120ピクセルより内側、中央寄りに置けば** 、比率がどう変わっても困りません。

## 画像ファイルの作り方

Instagramに上げるのは 1080×1350（4:5）、JPEG か PNG、最大20枚です。2つの方法があります。

**方法A：Canvaなどのデザインツールに手で流し込む**
日本ではこれがいちばん多い方法です。下の「出力」の文章を1枚ずつコピーして貼ります。このスキルが作るのは文章と構成までです。

**方法B：HTMLで作って画像にする**
1枚を `<section>` ひとつにして、`width:1080px; height:1350px`、アクセント色は1色、文字は最小でも32px。手元で使っているHTML→画像の方法（ブラウザで開いてスクリーンショット、PDFに印刷して画像に書き出す、など）で書き出します。
プロジェクトにブランドの決まりやデザインシステムがあればそれを使い、勝手に配色を作らないでください。

**日本語フォントについて（方法Bで大事）**
日本語の文字を出すには日本語フォントが必要です。このパックにはフォントを同梱していません。CSSでは、Macに最初から入っているフォントを先に並べます。

```css
font-family: "Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP",
             "Yu Gothic", "Meiryo", sans-serif;
```

書き出した画像で文字が「□」（とうふ）になっていたり、明らかに違う書体になっていたら、日本語フォントが見つかっていません。画像を作り直す前にユーザーへ伝えます。Webフォントを読み込む方法もありますが、書き出す前に読み込みが終わっているか必ず確認します。

## 出力

まず **1枚ずつの文章** を、10秒で読めて画像にする前に直せる番号つきの一覧で出します。次に **キャプション**。カルーセルの場合、表紙で文字数を使い切っているので、キャプションにも仕事があります（`insta-caption` でいう「キャプション自体に読ませる役目がある」型。元版では Job B）。

どちらも `insta-natural` を通して、AIっぽい言い回しを取ります。画像ファイルは、ユーザーが文章を確認してOKを出してから作ります。

```
カルーセル ・ 8枚

1  表紙    やめたら貯まった 固定費5つ
           月{{あなたの数字}}円浮いた見直し方
2  なぜ    節約は「我慢」より「やめる」が続く
3          スマホ代
           格安プランに変えて、毎月の差額を先取り貯金へ
...
7  まとめ  5つを1枚で
8  お願い  見直す日に見返せるよう、保存しておいてね

キャプション：キャプション自体に読ませる型。1行目にフック、お願いはひとつ、ハッシュタグは少なめ。
要確認：{{あなたの数字}} を実際の金額に置き換えてください。
```

このスキルは何もアップロードしません。投稿するのはユーザー本人です。
