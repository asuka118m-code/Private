# insta-review（振り返り係）

そのアカウントで何が効くかを正直に教えてくれるのは、そのアカウント自身の数字だけです。
どのInstagram攻略法も、このパックに書いてあることも含めて、すべて「事前の思い込み」です。ユーザー自身の直近30本が証拠です。

## 用意してもらうもの

あるものを出してもらいます。

- 投稿ごとのインサイト（プロアカウントで見られる数字）：再生数、リーチ（届いたアカウント数）、反応、平均再生時間、保存数、シェア数、フォロー数、リーチのうち **フォロワー以外** の割合。スクショで大丈夫です。
- または、いちばん良かったリールと悪かったリールの **視聴維持のグラフ**（どの秒で何割が残っていたか）。この1枚は、ほかの全部を合わせたより価値があります。
- または、投稿と再生数だけ。1回目の振り返りにはこれでも足ります。

`~/.claude/insta-ai-shain/log.md` があれば読みます。各投稿でどのフックの型を使ったかが記録されています。形式は決まっていなくて大丈夫です。日付・形式・フックの型番号・1行目が読み取れれば使えます。足りない列はユーザーに聞きます。

インサイトの項目名は、アプリの更新で名前や場所が変わることがあります。画面に見当たらない項目は無理に求めず、ある数字だけで進めます。**数字を推測で埋めることはしません。** 無い数字は「なし」と書きます。

## 本当に見る数字

再生数は、画面の中でいちばん役に立たない数字です。大部分は「すでにフォロワーが何人いるか」で決まるからです。代わりに次を計算し、計算の過程も見せます。

| 指標 | 計算 | わかること |
| --- | --- | --- |
| **外れ値倍率** | 再生数 ÷ そのアカウントの再生数の中央値 | 本当のヒットか、ふだんの日か |
| **リーチあたりの保存** | 保存数 ÷ リーチ | あとで見返したい中身だったか。日本では保存が特に重視されがち |
| **リーチあたりのシェア** | シェア数 ÷ リーチ | 獲得できるいちばん強いシグナル。シェアは「自分の名前で人に勧める」行為 |
| **フォロワー以外の割合** | リーチのうちフォロワー以外の％ | そもそも外に広がったか |
| **冒頭の残存** | 最初の数秒で離脱しなかった割合（インサイトに項目があれば） | フックが効いたか。これがフックの成績表 |
| **平均再生時間** | インサイトの数字そのまま | 中盤がもったか |
| **リーチあたりのフォロー** | フォロー数 ÷ リーチ | プロフィールが注目をフォローに変えられたか |

※中央値＝並べたときに真ん中に来る値。1本の大バズに引っぱられないので、平均より「いつもの数字」に近くなります。

**並べる順番は、外れ値倍率と、リーチあたりの保存・シェア。再生数ではありません。**
4,000回再生で保存120・シェア90のリールは、6万回再生で保存30・シェア11のリールに勝っています。

## それから、違いを探す

上位5本と下位5本を並べ、何が分けているのかを探します。ユーザーが聞きたくない結論になってもかまいません。

- **冒頭の残存。** 上位と下位でここが違うなら、原因はフックで、それ以外の心配は全部その後ろの話です。
- **フックの型。** 上位5本に `insta-reel` の hooks.json のどの番号が多いか。
- **形式。** リール、カルーセル、1枚画像。
- **長さ。** 15秒未満、15〜30秒、30〜60秒、60秒超で分ける。
- **テーマ。**
- **最初の1時間にコメントへ返信したか。**
- **曜日と時間。** これは **最後に**、ほかで何も見つからなかったときだけ見ます。原因であることはほとんどなく、なのにみんなが原因であってほしいと思う場所です。

見つかったことは「主張＋根拠」の形で書き、どのくらい確かかを言います。30本あればパターンが見えます。6本では見えません。無理にパターンを作るより、そう言うほうが役に立ちます。

## 何か月も無駄にしないための区別

**再生されたのにフォローされないリールは、失敗したリールではなく、プロフィールの問題です。**
**再生されないリールは、フックの問題です。**
何かを勧める前に、この2つを分けます。フォロワー以外へのリーチが多いのに、リーチあたりのフォローが少ないなら、フックの書き直しはやめて `insta-profile` に回します。

## 出力

```
振り返り ・ 31本 ・ 6/12〜9/5 ・ 再生数の中央値 4,100

外れ値倍率の上位5本
  18.2倍  #11  7.46万回  フォロワー外62%  保存/リーチ 3.1%  シェア/リーチ 1.7%
   6.4倍  #3   2.63万回  フォロワー外48%  保存/リーチ 2.4%  シェア/リーチ 0.9%
  ...

下位5本
   0.3倍  #5   1,200回   フォロワー外9%   保存/リーチ 0.2%  シェア/リーチ 0.0%
  ...

データからわかること
1. 冒頭の残存がすべて。上位5本の平均66%、下位5本は33%。
   ほかに気にしていることは、全部「最初の2秒」の後ろの話です。
2. 自分の失敗を話した回：平均8.1倍、それ以外は0.9倍。n=5（5本）。
   いちばん強いシグナルで、差もはっきりしています。
3. 「おすすめアプリ◯選」系は再生だけ取れて、保存もフォローも来ない。下位5本のうち3本。
4. 曜日の差は見えません。火曜と金曜の平均は誤差の範囲。そこを調整するのはやめましょう。

やめる：「◯選」の一覧もの
増やす：自分が払ったものと、その数字がある話
```

※上の例の数字はすべて説明用の架空のものです。本番ではユーザーが出した数字だけを使い、計算の過程を見せます。

結論は `insta-plan` に渡して、来週の計画を一般論ではなくユーザー自身の証拠で組めるようにします。また `insta-buzz` に渡して、ネタ帳をこのアカウントで実際に効いている型に絞り込めるようにします。

このスキルはInstagramにログインせず、数字を取りに行きません。ユーザーが見せてくれた数字だけで判断します。
